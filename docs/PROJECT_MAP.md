## Обозначения

| Метка | Что значит |
|---|---|
| ✅ **проверено** | Работает и подтверждено на живом портале Битрикс24 или живым прогоном |
| 🧪 **сделано** | Код написан и покрыт тестами, но вживую не прогонялось |
| 🔨 **в работе** | Начато, не закончено |
| ⏸️ **отложено** | Осознанно не делаем сейчас; причина указана |

## 1. Общее состояние

Проект **переписан** со старой раскладки (4 отдельных сервиса: backend, MCP-сервер, UI,
PHP-модуль в коробке) на **единый процесс Nuxt 4 + Nitro**. Старый код лежит в `legacy/` — только
как источник для переноса удачных кусков, новыми проверками не покрывается.

Ядро работает и подтверждено вживую. До публикации в Маркете осталось закрыть гейты (§7).

**Автотесты:** 1160, зелёные в CI на каждый PR. Проверки: `pnpm check` (линт + типы + тесты).

| Часть | Состояние | Комментарий |

| Извлечение текста: PDF, Office | ✅ проверено | `pdftotext`, `libreoffice` |
| Распознавание сканов и фото | ✅ проверено | `tesseract`, языки рус/бел/каз/англ |
| Распознавание нейросетью | ✅ проверено | Реальные счета РБ и РФ: тип, УНП/ИНН, позиции, НДС |
| Провайдер BitrixGPT (по умолчанию) | ✅ проверено | `pnpm verify:chat --provider bitrixgpt` |
| Провайдер DeepSeek | ✅ проверено | Опция; юрисдикция КНР |
| Проверка ответа модели | 🧪 сделано | Ответ — недоверенные данные |

**Про безопасность разбора.** Модель работает без инструментов и без доступа к порталу: получает
текст, возвращает JSON. Инструкция, спрятанная в документе, не может ничего, кроме как испортить
свой же JSON. Раньше агент имел инструменты — при большом ревью это нашли как **критичную** дыру
(можно было вытащить секреты) и убрали.

## 8. Отложено осознанно

| Что | Почему |
|---|---|
| ⏸️ **Чат-бот Битрикс24** | Сценарий деприоритизирован, старые порталы не дают нужный API. Код и обработчики оставлены, регистрация убрана из установки. Вернём при переходе на свежие порталы |
| ⏸️ **Создание товаров в каталоге** | Слишком рискованная операция в чужом каталоге по распознанному тексту. Вместо этого — пропуск строки или произвольная позиция |
| ⏸️ **КП как цель импорта** | Входящий документ в исходящее предложение вносить нечего |
| ⏸️ **Мультиязычный интерфейс** | Пока только русский |
| ⏸️ **Точное серверное время REST-вызовов** | Требует переделки, которая несоразмерна пользе; хватает косвенной оценки |
| ⏸️ **Переписывание истории git ради удалённого дампа** | Файл пустой, данных нет; переписывание сломало бы форки и клоны |

## 9. Известные ограничения

Честный список того, что не покрыто:

- **Гонка при «зависшем» воркере.** Защита от дублей работает для последовательных повторов
  (воркер упал — задача вернулась). Случай «живой, но потерявший блокировку воркер параллельно со
  второй репликой» не воспроизводился и остаётся открытым.
- **Нагрузочный прогон — на модели.** Реальные вызовы к Битрикс24 в нём не участвуют; отдельно
  проверяется только ограничитель.
- **Не проверялось:** повторы упавших задач и поведение при ошибке обработчика, падение и возврат
  Redis/Postgres под нагрузкой, срок жизни статусов при очень длинной очереди, интерфейс под
  нагрузкой.
- **Стадия лида** подтверждена только на упрощённом портале.

## 10. Раскладка репозитория

```
app/          интерфейс: страницы, компоненты, чистые функции (+ тесты)
server/       backend: api, очереди, работа с Битрикс24, разбор нейросетью
tests/        1160 автотестов (чистое ядро + компоненты)
scripts/      живые проверки и нагрузочные прогоны (не входят в сборку)
docs/         эта документация
legacy/       старый проект — только для переноса кусков, не собирается
deploy/       выкладка
```

**Соглашения:** комментарии в коде — по-английски, всё, что видит пользователь, и документация —
по-русски. Чистые функции отделены от ввода-вывода и покрыты тестами. Данные из портала выводятся
только через экранирование.

## 11. Живые проверки

Требуют доступа к тестовому порталу и ключа нейросети (в репозиторий не коммитятся).

| Команда | Что проверяет |
|---|---|
| `pnpm check` | Линт + типы + все автотесты |
| `pnpm sdk:smoke` | Транспорт к порталу: 30 запросов подряд без отказа |
| `pnpm verify:chat` | Распознавание документа нейросетью |
| `pnpm live:crm --ai` | Полный проход: текст → нейросеть → сделка с позициями → уборка |
| `pnpm verify:idem` | Повтор одним идентификатором не создаёт дубль |
| `pnpm loadtest:123` | Ограничитель запросов к порталу |
| `pnpm loadtest:queue` | Очередь под нагрузкой + реальный темп ограничителя |
